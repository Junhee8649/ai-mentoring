# AI 멘토링 활동 도구

학교급과 차시별로 모아 둔 수업 진행용 도구.
표준 프로그램의 활동을 그대로 쓰되, **교구가 없거나 진행이 어려운 부분만** 새로 만든다.

👉 **[도구 목록 열기](https://junhee8649.github.io/ai-mentoring/)**

> ⚠️ 도구 화면에는 멘토용 패널(정답·진행 메모)이 함께 있습니다.
> **아이들에게 주소를 직접 주지 마세요.**

## 지금 있는 것

| 학교급 | 차시 | 도구 | 주소 |
|---|---|---|---|
| 초등 고학년 | 10 · 치우친 자료가 만든 실수 | **속지 마!** | [/elem-senior/10-biased-data/](https://junhee8649.github.io/ai-mentoring/elem-senior/10-biased-data/) |

## 폴더 규칙

```
<학교급>/<차시번호>-<슬러그>/index.html
```

학교급 키는 넷이다.

| 키 | 뜻 |
|---|---|
| `elem-junior` | 초등 저학년 |
| `elem-senior` | 초등 고학년 |
| `middle` | 중학교 |
| `high` | 고등학교 |

**학교 이름으로 나누지 않는다.** 도구는 특정 학교가 아니라 학교급×차시에 붙는 것이라,
같은 학교급이면 다른 학교에서도 그대로 쓴다. 학교별 운영 조건(인원·기기·일정)은
저장소 밖 `schools/` 에 따로 적어 둔다.

## 도구를 추가하려면

1. `<학교급>/<차시>-<슬러그>/index.html` 로 파일을 만든다
2. `index.html` 의 `TOOLS` 배열에 한 줄 넣는다
3. 커밋하고 푸시하면 1~2분 뒤 반영된다

## 도구를 만들 때 지키는 것

원본 데모(`ai-mentor.kr`)의 설계 원칙을 그대로 따른다.

- 화면은 멘토의 말을 대신하지 않는다. **결론은 화면이 말하지 않고 멘티가 말한다**
- 정답·다음 순서·조작부는 **학생 화면에 가지 않는다**
- 점수와 순위를 매기지 않는다
- 사람·외모·집단을 소재로 쓰지 않는다. **특정 상표와 캐릭터를 넣지 않는다**

기술적으로도 교실에서 깨지지 않게:

- **외부 폰트·이미지·스크립트 금지.** 단일 HTML로 만들고 그림은 인라인 SVG
  (교실 인터넷이 막혀도, 파일만 받아 더블클릭해도 돌아가야 한다)
- 창 분리는 `BroadcastChannel`이 아니라 **`opener` + `postMessage`**
  (`file://` 는 origin이 opaque라 BroadcastChannel이 죽는다)
- 자동 타이머로 넘기지 않는다. **진행은 멘토가 스페이스바로** — 반 호흡과 어긋나면 활동이 무너진다
