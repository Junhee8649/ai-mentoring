# AI 멘토링 활동 도구

학교급·차시별 수업 진행용 도구.
표준 프로그램(`ai-mentor.kr`)의 활동을 그대로 쓰되, **교구가 없거나 진행이 어려운 부분만** 새로 만든다.

👉 **[도구 목록](https://junhee8649.github.io/ai-mentoring/)**

> ⚠️ 도구 화면에는 멘토용 패널(정답·진행 메모)이 함께 있다.
> **아이들에게 주소를 직접 주지 말 것.**

| 학교급 | 차시 | 도구 |
|---|---|---|
| 초등 고학년 | 10 · 치우친 자료가 만든 실수 | [속지 마!](https://junhee8649.github.io/ai-mentoring/elem-senior/10-biased-data/) |

---

## 도구를 추가하려면

1. `<학교급>/<차시번호>-<슬러그>/index.html` 을 만든다
2. `index.html` 의 `TOOLS` 배열에 한 줄 넣는다
3. 커밋·푸시하면 1~2분 뒤 반영된다

학교급 키는 넷: `elem-junior`(초저) · `elem-senior`(초고) · `middle`(중) · `high`(고)

**학교 이름으로 나누지 않는다.** 도구는 학교급×차시에 붙는 것이라 같은 학교급이면
다른 학교에서도 그대로 쓴다. 학교마다 다른 운영 조건은 저장소 밖 `schools/` 에 적는다.

## 만들 때 지키는 것

### 진행 원칙 — 원본 데모의 설계를 따른다

- 화면은 멘토의 말을 대신하지 않는다. **결론은 화면이 말하지 않고 멘티가 말한다**
- 정답·다음 순서·조작부는 **학생 화면에 가지 않는다**
- 자동 타이머로 넘기지 않는다. **진행은 멘토가 스페이스바로** — 반 호흡과 어긋나면 활동이 무너진다
- 멘토가 개념을 설명해야 하는 구조를 만들지 않는다. **멘티가 스스로 발견하고 멘토는 되묻는다**

### 기술 제약 — 교실에서 깨지지 않게

- **외부 폰트·이미지·스크립트 금지.** 단일 HTML, 그림은 인라인 SVG
  (인터넷이 막혀도, 파일만 받아 더블클릭해도 돌아가야 한다)
- 창 분리는 `BroadcastChannel`이 아니라 **`opener` + `postMessage`**
  (`file://` 는 origin이 opaque라 BroadcastChannel이 죽는다)
- 큰 글씨. 교실 뒷자리에서 읽혀야 한다

### 학교급별 AI 사용 범위

| 학교급 | 범위 |
|---|---|
| 초등 | **멘토 시연만.** 학생 계정 없음. 언플러그드·교구 중심. 만 14세 미만은 범용 AI를 직접 쓰지 않는다 |
| 중학교 | 시연 기본 + 약관 충족 시 보조적으로 직접 |
| 고등학교 | 직접 사용 가능하되 **'비판적 평가'·'책임 있는 활용'** 요소를 반드시 포함 |

무로그인 체험 도구(티처블 머신 · Quick, Draw! · AutoDraw)는 전 학교급 학생 직접 가능.
게임·규칙 활동은 범용 AI보다 **전용 데모를 우선한다** — 결과가 매번 달라지면 수업이 도박이 된다.

### 내보내기 전 점검

- [ ] 이해 / 비판적 평가 / 책임 있는 활용 중 **하나 이상**을 담고 있나
- [ ] "AI 답 = 정답"이라는 인상을 주지 않나
- [ ] AI를 친구·사람처럼 대하게 만들지 않나
- [ ] 판단의 주인이 멘티인가 (AI와 도구는 재료)
- [ ] **사람·외모·집단**을 함정이나 분류 소재로 쓰지 않았나
- [ ] **특정 상표·캐릭터**가 화면에 없나 (게임 이야기는 멘토가 입으로)
- [ ] 점수나 순위를 매기지 않나
- [ ] 틀린 아이가 놀림받을 구조가 아닌가 — "다 같이 틀렸다"로 정리되나
