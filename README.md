# 속지 마!

초등 고학년 AI 멘토링 **10차시 「치우친 자료가 만든 실수」** 전반부(0~22분) 진행 도구.

👉 **[바로 열기](https://junhee8649.github.io/sokjima/)**

- **STAGE 1 · 말놀이 함정** — 열 번 외친 말에 휩쓸려 다 같이 틀린다
- **STAGE 2 · 전설템 감별사** — 편향된 예시 여섯 장으로 배운 뒤, 색만 보고 틀린다

두 판 모두 *"앞에서 뭘 받았느냐가 판단을 정한다"* 는 한 가지를 몸으로 겪게 한다.
그다음 [치우친 자료 실험실](https://ai-mentor.kr/resources/demo/biased-lab/index.html)로 넘어가
**기계도 똑같이 틀리는 것**을 확인한다.

## 쓰는 법

1. 노트북과 TV를 **확장 모드**로 연결 (`Win`+`P` → 확장) — 복제로 하면 멘토 패널이 아이들에게 다 보인다
2. `🖥 학생 화면 열기` → 열린 창을 TV로 끌어다 `F11` 전체화면
3. 진행은 **`Space`**(다음) / **`←`**(이전) 뿐

오른쪽 멘토 패널에 경과 시간, 정답, 다음에 벌어질 일, 활동을 죽이는 실수가 뜬다.
**이 패널은 학생 화면에 절대 가지 않는다.**

> ⚠️ 이 페이지를 아이들에게 직접 보여주지 말 것. 멘토 패널에 정답이 그대로 있다.

## 설계 원칙

- 화면은 멘토의 말을 대신하지 않는다. **결론은 화면이 말하지 않고 멘티가 말한다**
- 정답·다음 순서·조작부는 학생 화면에 가지 않는다
- 점수와 순위를 매기지 않는다
- 사람·외모·집단을 소재로 쓰지 않는다. 특정 상표와 캐릭터를 넣지 않는다

## 기술

단일 HTML 파일. **외부 폰트·이미지·스크립트·네트워크 호출 없음** — 파일만 내려받아
더블클릭해도 그대로 돈다. 카드와 아이콘은 전부 인라인 SVG.
창 동기화는 `BroadcastChannel`이 아니라 `opener` + `postMessage` (`file://`에서도 살아 있어야 하므로).

## 문제 바꾸기

`CHANTS` 배열을 고친다. 규칙 셋:

1. **반복한 단어가 곧 오답이어야 한다** — 아니면 공개 화면이 원인을 설명하지 못한다
2. **정답은 5·6학년이 100% 아는 것이어야 한다** — 모르면 함정이 아니라 그냥 퀴즈다
3. **유치해 보이는 건 난이도가 아니라 소재다** — 난이도는 그대로 두고 소재만 올린다
